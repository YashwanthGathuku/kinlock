Nebius Token Factory · NVIDIA Nemotron

A real Nemotron agent, on the verified path.

Kinlock signs the intent for each spoken task. Ultra plans and calls tools while holding that token; Nano adds scam cues, which can only make a decision stricter. Every consequential call carries a certificate.

Policy changes in plain language

Nemotron may propose a rule change. It can't make one.

The owner's sentence goes to Nemotron Ultra. Its JSON is treated as untrusted, validated strictly and classified by Kinlock's deterministic engine. Nothing is applied here, and any increase needs the owner's own confirmation.

Evidence · Tavily + Nemotron Nano

Web evidence can add caution. It can't add authority.

For a fixed set of scam claims, Tavily searches official sources and Nano classifies whether they conflict with the claim. A conflict adds one risk signal; missing or supporting evidence changes nothing.

Invariant

No model is an approval authority.

Models may PROPOSE

Plan tasks, propose tool calls, delegate narrower authority, flag scam signals, summarise evidence, and explain decisions.

Models may not AUTHORIZE

Widen an intent, forge a delegation or evidence, misdescribe an effect, outlive a revocation, replay a commit, or mint a token.
